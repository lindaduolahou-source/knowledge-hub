# Knowledge Hub App 产品路线图

目标：你是开发者，控制「所有人看到的默认产品界面与内容」；  
普通用户登录后，每人拥有自己的私人数据，互不影响。

---

## 总览

| 阶段 | 目标 | 状态 |
|------|------|------|
| **阶段 1** | 公开默认内容：你改 → 所有访客/用户看到 | 进行中 |
| **阶段 2** | 每用户独立数据：登录后读写自己的库 | 规划中 |
| **阶段 3** | 新用户注册时复制默认模板到私人库 | 可选后续 |

---

## 阶段 1：公开默认内容（开发者 → 所有人）

### 谁改、谁看
- **你（站长邮箱登录）**：编辑网站内容 → 写入 Supabase `site_stores`
- **未登录访客 / 未登录打开 App 的人**：自动拉取 `site_stores`，看到你维护的默认内容
- **普通用户（阶段 2 之后）**：先看到默认内容；登录后进入自己的私人数据

### 你的日常流程（阶段 1）
1. 本地或线上用**站长邮箱**登录  
2. 改页面上的文案、模块、章节等  
3. 自动同步到 `site_stores`  
4. 其他人刷新网站即可看到（无需再手动 export）

### 技术要点
- 表：继续用 `public.site_stores`（整站一份「官方默认」）
- 进入网站时：即使未登录也会 **读取** `site_stores`
- 只有站长邮箱登录后才会 **写入** `site_stores`
- 回收站、名片仓库等偏私人工具，也可暂存在此；阶段 2 再拆到用户库

### 阶段 1 完成标准
- [ ] 站长登录修改「同步测试」类文案后，无痕窗口（未登录）刷新也能看到  
- [ ] 非站长账号（若存在）不能改写 `site_stores`  
- [ ] Vercel 生产环境同样生效  

---

## 阶段 2：每用户独立数据库

### 谁改、谁看
- **普通用户登录后**：只读写自己的数据  
- **未登录**：只看阶段 1 的官方默认内容  
- **你（开发者）**：继续维护官方默认；自己的私人编辑可放在自己的 `user_id` 下，或继续当站长维护默认

### 新表（规划）

```text
public.user_stores
- user_id   uuid   → auth.users.id
- name      text   → 与现在 store 名相同
- payload   jsonb
- updated_at timestamptz
主键：(user_id, name)
```

### RLS（规划）
- 用户只能 `select/insert/update/delete` **自己的** `user_id` 行  
- `site_stores` 保持：所有人可读；仅站长可写（或仅 service role / 站长策略）

### 同步逻辑（规划）
1. 打开 App → 拉取 `site_stores` 作为默认层  
2. 用户登录 → 再拉取 `user_stores`（该用户）覆盖到本地私人层  
3. 用户编辑 → 只写入 `user_stores`，永不写进别人的数据  
4. 用户登出 → 回到默认层展示  

### 阶段 2 完成标准
- [ ] 用户 A、B 登录后内容互不影响  
- [ ] 未登录仍只看到官方默认  
- [ ] 站长更新默认后，新访客/新用户能看到新默认（已有用户私人数据不被覆盖，除非做「重置为默认」）

---

## 阶段 3（可选）：注册时复制模板

- 新用户首次登录：把当前 `site_stores` 复制一份到其 `user_stores`  
- 之后他改自己的，不影响官方默认，也不影响其他用户  

---

## 建议工作顺序

1. **现在：阶段 1 代码** — 未登录也拉取公开默认；仅站长可写  
2. **你：改默认内容** — 登录站长账号，把呈现给用户的页面改到满意并部署  
3. **然后：阶段 2** — 建 `user_stores` + RLS + 改同步逻辑  
4. **最后：阶段 3** — 注册复制模板（可选）  
5. **产品化** — 重新打开公开注册、确认邮箱、完善 AI/名片等功能  

---

## 和当前仓库的对应关系

| 概念 | 现在 | 阶段 1 | 阶段 2 |
|------|------|--------|--------|
| 官方默认 | 代码字典 + 空的 published-site + 站长 localStorage | `site_stores` 全民可读 | 同左 |
| 站长编辑 | 登录后 sync | 仅站长写入 `site_stores` | 可继续维护默认 |
| 用户私人 | 无 | 无 | `user_stores` |
| 登录按钮 | 站长用 | 站长用 | 所有用户用 |
